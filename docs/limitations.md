# Limitations

Six selected packages and one downstream repository are not representative. Explicit deprecation can apply to a particular version while other release lines remain maintained. Latest-version advisory counts do not describe a downstream declared range or lockfile; lockfile resolution and transitive analysis are not implemented. Raw upstream responses can change; committed derived outputs and response hashes preserve what was observed without copying maintainer emails.

Two manifest snapshots establish differences only. They do not detect rename intent, a particular replacement, exact update time, or historical deprecation onset. Response timing and causal risk prediction are not claimed. Repository and release activity can reflect unrelated monorepo work or stability.

Unknown and unavailable data must remain distinguishable from negative evidence. Raw caches contain public metadata and stay local; only necessary, derived fields are published. OSV pagination that exceeds one response is marked unknown, not counted as complete. Normal CI does not contact public data APIs. No live Vercel deployment is claimed by local build verification.
